This repository relates to the Critical Discourse Analysis experiments carried out using LLMs. 

The "docs" folder contains the articles used for the experiment (Articles.md), the questions posed to human raters and to the LLMs (Questions.md), and the prompts used to query the LLMs (Prompts.md).

The "data" folder contains the results of the experiment. Specifically, the inter-rater agreement measures and consensus for both the human raters and the two LLMs are reported in the relative spreadsheets.
