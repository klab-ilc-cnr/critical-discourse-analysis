This repository relates to the Critical Discourse Analysis experiments carried out using LLMs. 

The "docs" folder contains the articles used for the experiment (Articles.md), the questions posed to human raters and to the LLM (Questions.md), and the prompts used to query the LLM (Prompts.md).

The "data" folder contains the results of the experiment. Specifically, the spreadsheet "raw_data.xlsx" reports all the answers provided by the three human raters and the LLM runs. The inter-rater agreement measures and consensus for both the human raters and the LLM are reported in the spreadsheets "Human_inter-agreement_and_consensus.xlsx" and "LLM_inter-agreement_and_consensus.xlsx", respectively.
